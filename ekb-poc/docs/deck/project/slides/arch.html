Publish flow: a document is only indexed after all four approvals. The file moves through lake zones in MinIO: staging, raw, processed (markdown and tables) and curated (chunks). The pipeline extracts with PyMuPDF, enriches with the LLM (summary, entities, key info), chunks to 400 to 800 tokens without splitting tables, embeds with BGE-M3 locally, and indexes into Elasticsearch and Neo4j. A new version supersedes the old one automatically. Ask flow: a router picks documents, data or both. Documents use keyword plus vector search merged by reciprocal rank fusion, then graph expansion. Data uses text-to-SQL through Trino with a SQL guard. The answer model is gpt-4.1-mini for the POC; embeddings stay local.
