What the POC proves

Four capabilities, working end to end

Governed intake

Four-step maker-checker approval with segregation of duties. Exact and near duplicates are caught before anything is published.

Cited answers

Keyword and vector search, expanded through a knowledge graph. Every statement cites the document, version and page.

Data questions

Text-to-SQL through Trino over curated views. The generated SQL is shown, checked and limited to read-only queries.

Security and lineage

Results trimmed to each user's access groups in every store. An append-only audit trail records every action, query and model call.
